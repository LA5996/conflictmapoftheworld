# Conflict Map of the World

Free, independent, sourced world map of armed conflicts, day-to-day violence, natural disasters, political changes and economic ties. Live at **https://conflictmapoftheworld.com**.

- `index.html`, `assets/`: the static site (no server, no cookies, no tracking).
- `data/*.json`: the content. Refreshed every morning; each entry carries its sources.
- `.github/workflows/deploy.yml`: checks the data and publishes to GitHub Pages on every change.

Spotted an error? Open an issue with a link to a reliable source.
